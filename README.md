# 김대환 앱 모음

인스타/유튜브 프로필에 거는 다운로드 페이지. 아이폰은 앱스토어, 안드로이드는 플레이스토어로 보낸다.

- `index.html` 전체 목록
- `go.html?a=<id>` 앱 하나로 바로 보내는 주소 (영상 설명란용)
- `apps.js` 앱 목록

## 새 앱 추가
1. `icons/<id>.png` 에 256x256 아이콘을 넣는다.
2. `apps.js` 의 `APPS` 맨 위에 한 줄 추가한다. (`ios` 는 앱스토어 숫자 ID, `android` 는 패키지 이름)
3. 커밋하고 push 하면 배포된다.
